# MilkApiManager Onboarding Guide

歡迎加入 **Milk API Manager System** 開發團隊！這份文件將幫助你快速理解專案的結構、核心邏輯與開發規範。

## 1. 專案概觀 (Project Overview)

*   **專案名稱**: MilkApiManager
*   **版本**: 1.0.0
*   **主要語言**: C# (.NET 8), TypeScript, Lua, Python, PowerShell
*   **核心框架**: 
    *   **Backend**: ASP.NET Core 8, Entity Framework Core
    *   **Gateway**: Apache APISIX 3.11 (Lua Plugins)
    *   **Frontend**: Blazor Server + MudBlazor 8
    *   **Observability**: Prometheus, Grafana, ELK Stack
    *   **Infrastructure**: Docker, Docker Compose, Helm

**專案定位**: 這是一個企業級的 API 生命週期管理與安全治理平台，結合了控制平面 (Control Plane, .NET) 與數據平面 (Data Plane, APISIX)。

## 2. 架構分層 (Architecture Layers)

專案採用清晰的層級化架構，以下是各層的主要職責：

### 🏗️ Infrastructure (基礎建設)
管理 API Gateway 配置與監控指標。
*   `apisix_conf/`: APISIX 路由、插件與全域配置。
*   `monitoring/`: Prometheus 告警規則與 Grafana 儀表板。
*   `deploy/`: Helm Charts 用於 Kubernetes 部署。

### 🔌 API (介面層)
對外提供的管理 REST API。
*   `backend/MilkApiManager/Controllers/`: 包含 API 管理、Consumer 管理、安全規則設定等端點。

### ⚙️ Service (業務邏輯層)
處理核心業務規則與後台任務。
*   `AuthService.cs`: 處理 JWT 與權限驗證。
*   `BlacklistService.cs`: IP 黑名單同步邏輯。
*   `KeyRotationBackgroundService.cs`: 自動化金鑰輪轉。

### 💾 Data (資料持久層)
資料庫模型與存取介面。
*   `backend/MilkShared/Data/AppDbContext.cs`: EF Core 資料庫上下文。
*   `backend/MilkShared/Models/`: 跨專案共用的實體模型。

### 🖥️ UI (管理後台)
基於 Blazor 的深色模式管理界面。
*   `backend/MilkAdminBlazor/Pages/`: 包含儀表板、API 庫存、同步狀態等頁面。

## 5. 開發注意事項 (Development Notes)

### 🚨 複雜度熱點 (Complexity Hotspots)
*   **同步機制**: 專案使用 Outbox Pattern 確保資料庫與 APISIX 之間的一致性，修改 `ApisixSyncOutboxWorker.cs` 時需格外小心。
*   **Lua 插件**: Gateway 層的安全性檢查 (PII Masking, Traffic Blocking) 是在 APISIX 內部執行的，需具備基本 Lua 語法知識。
*   **SDK 生成**: 專案包含自動生成 Python SDK 的腳本 (`scripts/generate-python-sdk.ps1`)，修改 API 定義後需重新運行。

### 🧪 測試規範
*   單元測試位於 `backend/MilkApiManager.Tests`。
*   E2E 測試位於 `e2e/`，使用 Playwright 執行 UI 流程驗證。
